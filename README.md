# Event

Web app for planning events: create an event, design the room (tables and dance floor),
add guests with a password and manage the seating plan. Guests can log in and book their own seats.

Built with React, React Router and Firebase Firestore.

## Setup

1. Create a Firebase project with a Firestore database.
2. Copy `.env.example` to `.env` and fill in the values from your Firebase project settings.
3. Install and start:

```bash
npm install
npm start
```

## Scripts

- `npm start` – development server on http://localhost:3000
- `npm run build` – production build
- `npm test` – run the tests
